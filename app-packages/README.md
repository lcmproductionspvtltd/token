# BQuee app packages

Ready-to-build copies of both apps, for building on any computer.

| File | App | App id |
|---|---|---|
| `BQuee-Biz-1.0.0-build3.zip` | **BQuee Biz** – super admins, the BQuee team, business owners and staff | `com.ibill.bquee` |
| `BQuee-Customer-1.0.0-build3.zip` | **BQuee** – customers: scan a business QR, book tokens, see history | `com.bquee.customer` |

Each zip contains the app's full source code, **Build on Mac.command** (one click: Android + iPhone) and **HOW TO BUILD.txt** (also Windows/Linux steps for Android).

To download from GitHub: open the zip file above, then press **Download raw file**.

Made by `bash scripts/package-apps.sh` from the code in `mobile/` and `customer/` – run it again after app changes.
